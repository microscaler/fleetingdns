Introduction to FleetingDNS

"Instant, Zero‑Trust Tunnels for Modern Dev & Edge Workloads."

FleetingDNS is the secure, open, self‑hostable alternative to SaaS tunnels. It combines streamlined developer UX with Tailscale‑grade security, minus the lock‑in.

What is FleetingDNS?

FleetingDNSis a modern tunneling solution designed specifically for developers and enterprises that need secure, fast, and controllable access to their services. Built with 100% Rust, FleetingDNS provides instant tunnels with zero-trust security principles baked in from the ground up.

Unlike traditional SaaS tunneling solutions, FleetingDNS gives you complete ownership of your infrastructure while maintaining the ease-of-use developers expect and the security controls enterprises require.

Key Features

Speed

URLs live in under 2 seconds thanks to stateless DNS architecture. Get your services exposed instantly without waiting for propagation.

Security

Built with mTLS, DNSSEC-signed domains, and 30-minute certificate rotation. Zero-trust architecture ensures only authorized access.

Ownership

100% Rust codebase that you can run anywhere. No black boxes, no vendor lock-in. Complete transparency and control.

Enterprise Control

OIDC integration, HMAC verification, rate limiting, and comprehensive audit logging. Built for enterprise compliance.

Getting Started

Start using FleetingDNS in minutes with our simple installation and setup process. Here's a quick example:

Terminal 
# Install FleetingDNS
$ curl -sSL https://get.edf.dev | sh

# Start a tunnel to your local service
$ edf tunnel 8080
✓ Tunnel created! Your service is available at: https://dev-ab12c.edf.dev
✓ Secured with mTLS and DNSSEC
