## Slide 3 — Surface Symbolism: What Users See

| Element         | Visual meaning        | What it conveys                                 |
| --------------- | --------------------- | ----------------------------------------------- |
| ✈️ Paper plane  | Lightweight delivery  | **Fast DNS** or webhook-like message            |
| Single glyph    | Minimal + intentional | Purpose-built — like a **TTL = 30s** DNS record |
| Plane in motion | Directional flow      | A **packet** on the move                        |
| Paper           | Temporary, ephemeral  | Like tunnels or one-shot endpoints              |

---

## Slide 4 — Infra Engineer Subtext (Subliminal Layer)

| Subtle Cue               | Emotional impact                          |
| ------------------------ | ----------------------------------------- |
| No rocket / no cloud     | "Not bloatware." Functional, scoped.      |
| Disappears after use     | Matches ephemeral DNS lifespan.           |
| Not military or abstract | Feels **human-scale**, not over-designed. |
| Quiet confidence         | Delivers without fanfare — like DNS does. |

---

## Slide 5 — Brand Fit Summary

**Why it’s right for us:**

* FleetingDNS is:

    * **Ephemeral-first**: one-shot records, TTL-sensitive.
    * **Infrastructure-lite**: powerful, but not heavy-handed.
    * **Secure-by-design**: no flashy overstatements.
* The logo supports that without needing to explain it aloud.
