# ms02 (FleetingDNS perspective)

Shared dev host that runs the kind cluster, Docker daemon, kind-registry,
and (since 2026-04-20) Tilt itself for FleetingDNS development.

For hardware/OS facts, defer to the cylon-local-infra wiki — which lives
**on the operator's Mac** at
`~/Workspace/local/cylon-local-infra/llmwiki/entities/ms02.md` (the two
repos are on different machines; no relative link possible — see
"Workspace topology" below). This page only records FleetingDNS-specific
facts.

## Repo location on ms02

`/home/casibbald/Workspace/microscaler/fleetingdns` — sync'd by either
`just sync` (rsync) or the cylon-local-infra `playbooks/sync_workspace.yml`.

## Dev workflow

`just up` from the Mac:

1. rsync the working copy to the path above.
2. `ssh -L 10350:127.0.0.1:10350 casibbald@ms02 'cd <repo> && tilt up
   --context kind-kind --host 127.0.0.1 --port 10350 --stream'`.
3. Detach the ssh process; track its pid in `.kube/tilt.pid`; write
   tilt's stdout/stderr to `.kube/tilt.log`.

`just down` reverses it (`tilt down` on ms02, then SIGTERM the ssh pid).

See [tilt-remote-host-pattern](../concepts/tilt-remote-host-pattern.md)
for the rationale and the prior, more complex iteration that used
apiserver+registry SSH tunnels.
